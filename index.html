Themes

    size = posts with the tag line = tags on the same post

    scroll or pinch to zoom · drag a circle · select one to read

    Reading the graph

    • Themes are what a post is about; Tone is how it is written.
    • A circle's size is the number of distinct posts with that tag.
    • A line joins two tags that appear on the same post. Thicker lines mean they share more posts.
    • A post can carry several tags, so tag counts overlap.
